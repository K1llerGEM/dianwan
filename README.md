# 电玩之道

一个运行在 Windows 桌面上的游戏资讯小组件：每天启动时自动抓取 **Steam + 3DM + 游民星空** 三个来源的热门新游，按发售日期归档入库，用毛玻璃风格的悬浮小窗展示。想看哪天发售了什么游戏，点一下就行。

---

## 功能特性

- **多数据源**：Steam 热门新游 + 3DM 月度发售表 + 游民星空月度发售表，一个窗口全看到
- **自动补价**：3DM / 游民的游戏会通过 Steam 商店搜索接口自动补上价格（查不到的显示"—"）
- **自动更新**：程序启动即在后台抓取更新（约 400+ 款），无需手动刷新
- **按日期查游戏**：周一~周日按钮快速切换本周日期；"日历"按钮可任意翻年、翻月、选日期
- **有货日期标亮**：本周哪天有发售、日历里哪天有发售，都标成绿色
- **搜索功能**：顶部搜索框按游戏名模糊搜索（跨全部来源），支持翻页
- **来源标签**：每条游戏带彩色标签——蓝 `[Steam]`、橙 `[3DM]`、绿 `[游民]`
- **游戏列表**：每页 10 条，名字靠左（超长自动按像素截断）、价格靠右，行间有分割线
- **双击直达**：双击条目打开对应站点页面（Steam 商店 / 3DM 专题页 / 游民专题页）
- **毛玻璃界面**：Windows 10/11 亚克力毛玻璃效果，字体微软雅黑
- **桌面小窗**：置顶、可固定/取消固定、可拖动、记忆窗口位置
- **离线可用**：打包时内置种子数据库，别人电脑上没网也能先看到上次的数据
- **数据本地化**：数据库与设置统一存放在系统"文档"文件夹的 `Dao` 目录

## 项目结构

```
dianwan/
├── main.py        # 数据抓取：三个来源 → 解析 → 补价 → 写入 SQLite
├── widget.py      # 界面程序：桌面小窗（入口文件，双击运行这个）
├── games.db       # 打包用的种子数据库（从 Dao 目录复制过来）
└── README.md
```

| 文件 | 作用 |
| --- | --- |
| `main.py` | 抓取与入库逻辑，提供 `update_data()` 函数 |
| `widget.py` | 图形界面，启动时后台调用 `update_data()` 并展示数据 |
| `games.db` | SQLite 数据库（运行时在文档/Dao 目录自动生成） |
| `settings.json` | 窗口位置、固定状态记忆（运行时自动生成） |

## 环境要求

- Windows 10 / 11（毛玻璃效果需要系统开启"透明效果"）
- Python 3.10 及以上
- 可正常访问 Steam / 3DM / 游民星空的网络

### 依赖安装

```bash
pip install requests beautifulsoup4
```

## 运行

```bash
python widget.py
```

首次运行会显示"数据下载中"，底部加载条走完即自动展示游戏列表（抓取三源 + 补价，约 1~3 分钟；之后每次启动只需几十秒）。

---

## 数据存放位置

所有数据自动生成在系统"文档"文件夹的 `Dao` 目录：

```
C:\Users\你的用户名\Documents\Dao\
├── games.db        # 游戏数据库
└── settings.json   # 窗口设置
```

> 打包成 exe 后数据同样写在这里，exe 放哪都不影响数据；重装/换机只需备份这个 Dao 文件夹。

## 使用说明

1. **切换日期**
   - 顶部 **周一 ~ 周日**：显示本周每天的日期，点击直接查看该日发售的游戏
   - 右侧 **日历**：`◀◀ ▶▶` 切换年份、`◀ ▶` 切换月份，点任意日期查看
2. **看有货的日子**
   - 本周有游戏发售的日期，对应按钮显示为绿色
   - 日历里绿色日期 = 当天有游戏发售
3. **搜索游戏**
   - 顶部输入框输入关键词 → 点"搜索"或按回车 → 跨全部来源模糊匹配
   - 点"清除"（或点周几按钮/日历）回到按日期浏览
4. **浏览列表**
   - 每页 10 条；彩色标签表示来源，价格绿色加粗、无价格显示灰色"—"
   - 下方 `上一页 / 下一页` 翻页
5. **打开页面**：双击某条游戏，浏览器自动打开对应站点的游戏页面
6. **窗口操作**
   - 顶栏右侧：**固定 / 取消固定**（置顶开关）、**×** 关闭
   - 取消固定后可拖动窗口，位置会自动记住

## 打包成 EXE

```bash
pip install pyinstaller
```

**先刷新种子数据**（确保 `Documents\Dao\games.db` 是最新数据）：

```
Copy-Item "$env:USERPROFILE\Documents\Dao\games.db" "D:\dianwan\games.db"
```

单个 exe 文件（适合分发，启动稍慢）：

```bash
pyinstaller --noconfirm --onefile --windowed --name 电玩之道 --add-data "games.db;." widget.py
```

文件夹模式（启动更快，适合自用）：

```bash
pyinstaller --noconfirm --windowed --name 电玩之道 --add-data "games.db;." widget.py
```

- 产物在 `dist\电玩之道\电玩之道.exe`
- 改完代码重新打包：重复上面的复制 + 打包命令即可

> 注意：打包命令里 `games.db;.` 中间是**分号**（Windows 专用写法）。

## 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 首次打开是空白的 | 正常：正在后台抓取数据，底部有加载条，完成后自动显示 |
| 显示"更新失败（请检查网络）" | 网络无法访问数据源，检查网络/代理后重启程序 |
| 别人电脑上打开没数据 | 重新打包时忘了内置种子库——先刷新 `games.db` 再 `--add-data` |
| 杀毒软件报毒/拦截 | PyInstaller 打包的程序无数字签名，属正常现象，加入信任即可 |
| Windows 提示"已保护你的电脑" | 点"更多信息 → 仍要运行" |
| 窗口拖动不了 | 先点"取消固定"再拖动 |
| 某些游戏没有价格 | 该游戏不在 Steam 商店（主机独占等），查不到价格，显示"—"属正常 |
| 搜索不到想找的游戏 | 数据库只收录了抓取到的热门/发售表游戏；可调大 main.py 里的上限后重新运行 |
| 想抓更多游戏 | 修改 `main.py` 里的 `MAX_STEAM` / `MAX_3DM` / `MAX_GAMERSKY` 后重新运行 |

## 技术说明

**数据流**

```
Steam 热门新游 ─┐
3DM 月度发售表 ─┼─ 抓取解析 → 补价(Steam 商店搜索接口) → SQLite
游民星空发售表 ─┘                          ↓
                        桌面小窗 (tkinter 界面，按日期/关键词查询)
```

- 抓取接口：
  - Steam：`store.steampowered.com/search/results/?filter=popularnew`
  - 3DM：`3dmgame.com/release/pc{年月}/`（每页约 20 款，按 Steam 关注度排序）
  - 游民：`ku.gamersky.com/release/pc_{年月}/`（按月热度排序）
- 补价接口：`store.steampowered.com/api/storesearch/?term=游戏名&cc=cn&l=schinese`
- 表结构：`games(name, date, price, url, rank, week, source)`
  - `rank`：全局名次（同一天内按此排序，Steam 在前）
  - `week`：星期几（周一=0 … 周日=6）
  - `source`：数据来源（steam / 3dm / gamersky）
- 每次更新"先抓成功再重建表"，抓取失败保留旧数据
- 界面线程与抓取线程分离，抓取在后台进行，界面不卡顿
- 打包后用 `sys._MEIPASS` 定位内置种子库，首次运行自动复制到 Dao 目录

**免责声明**：本项目仅用于个人学习与兴趣，数据来源于各站公开页面，与 Steam / Valve / 3DM / 游民星空 无任何关联；请勿用于商业用途或高频抓取。
