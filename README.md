# 电玩之道

一个运行在 Windows 桌面上的游戏资讯小组件：每天启动时自动抓取 **Steam 热门新游**，按发售日期归档入库，用毛玻璃风格的悬浮小窗展示。想看哪天发售了什么游戏，点一下就行。

---

## 功能特性

- **自动更新**：程序启动即在后台抓取 Steam 热门新游戏（默认 300 款），无需手动点刷新
- **按日期查游戏**：周一到周日按钮快速切换本周日期；右侧"日历"按钮可任意翻年、翻月、选日期
- **有货日期标亮**：本周哪天有游戏发售，对应按钮标绿；日历里当天有发售的日期也标绿
- **游戏列表**：每页 10 条，名字靠左、价格靠右、行间有分割线，付费价格绿色显示
- **双击直达商店**：双击任意游戏条目，直接用浏览器打开对应 Steam 商店页
- **毛玻璃界面**：Windows 10/11 亚克力毛玻璃效果，字体微软雅黑
- **桌面小窗**：置顶显示、可固定/取消固定、可拖动、记忆窗口位置
- **数据本地化**：数据库和设置统一存放在系统"文档"文件夹的 `Dao` 目录，方便备份

## 项目结构

```
dianwan/
├── main.py        # 数据抓取：访问 Steam 热门新游列表 → 解析 → 写入 SQLite
├── widget.py      # 界面程序：桌面小窗（入口文件，双击运行这个）
├── read_db.py     # 教学练习：命令行读库（可选，不需要可删）
├── ceshhi.py      # 教学练习：requests 联网测试（可选，不需要可删）
└── requirements.txt
```

| 文件 | 作用 |
| --- | --- |
| `main.py` | 抓取与入库逻辑，提供 `update_data()` 函数 |
| `widget.py` | 图形界面，启动时后台调用 `update_data()` 并展示数据 |
| `games.db` | SQLite 数据库（运行时自动生成在文档目录的 Dao 文件夹） |
| `settings.json` | 窗口位置、固定状态记忆（运行时自动生成） |

## 环境要求

- Windows 10 / 11（毛玻璃效果需要系统开启"透明效果"）
- Python 3.10 及以上
- 可正常访问 Steam 商店的网络

### 依赖安装

```bash
pip install requests beautifulsoup4
```

## 运行

```bash
python widget.py
```

首次运行会先显示"数据下载中"，底部加载条走完即自动展示游戏列表（抓取约 300 款，约十几秒，之后每次启动只需几秒增量校验）。

---

## 数据存放位置

所有数据自动生成在系统"文档"文件夹的 `Dao` 目录：

```
C:\Users\你的用户名\Documents\Dao\
├── games.db        # 游戏数据库
└── settings.json   # 窗口设置
```

> 提示：打包成 exe 后数据也写在这里，所以 exe 放在任何位置都不影响数据，重装/换机只需备份这个 Dao 文件夹。

## 使用说明

1. **切换日期**
   - 顶部 **周一 ~ 周日**：显示本周每天的日期，点击直接查看该日发售的游戏
   - 右侧 **日历**：点开完整日历，用 `◀◀ ▶▶` 切换年份、`◀ ▶` 切换月份，点任意日期查看
2. **看有货的日子**
   - 本周有游戏发售的日期，对应按钮显示为绿色
   - 日历里绿色日期 = 当天有游戏发售
3. **浏览列表**
   - 每页 10 条，按热门程度排序；下方 `上一页 / 下一页` 翻页
4. **打开商店**：双击某条游戏，浏览器自动打开其 Steam 商店页
5. **窗口操作**
   - 顶栏右侧：**固定 / 取消固定**（置顶开关）、**×** 关闭
   - 取消固定后可拖动窗口，位置会自动记住

## 打包成 EXE

```bash
pip install pyinstaller
```

单个 exe 文件（启动稍慢，适合分发）：

```bash
pyinstaller --noconfirm --onefile --windowed --name 电玩之道 widget.py
```

文件夹模式（启动更快，适合自用）：

```bash
pyinstaller --noconfirm --windowed --name 电玩之道 widget.py
```

- 产物在 `dist\电玩之道\电玩之道.exe`
- 改完代码重新执行打包命令即可覆盖

## 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 首次打开是空白的 | 正常：正在后台抓取数据，底部有加载条，完成后自动显示 |
| 显示"更新失败（请检查网络）" | 网络无法访问 Steam，检查网络/代理后重启程序 |
| 杀毒软件报毒/拦截 | PyInstaller 打包的程序无数字签名，属正常现象，加入信任即可 |
| Windows 提示"已保护你的电脑" | 点"更多信息 → 仍要运行" |
| 窗口拖动不了 | 先点"取消固定"再拖动 |
| 某些游戏没有价格 | 该条目 Steam 页面未给出价格（如未定/免费），属正常数据 |
| 想抓更多游戏 | 修改 `main.py` 里的 `MAX_GAMES`（默认 300）后重新运行 |

## 技术说明

**数据流**

```
Steam 商店搜索页(热门新游)
        │  requests + BeautifulSoup 解析
        ▼
SQLite (games.db)
        │  按日期查询
        ▼
桌面小窗 (tkinter 界面)
```

- 抓取接口：`store.steampowered.com/search/results/?filter=popularnew&sort_by=Released_DESC`
- 表结构：`games(name, date, price, url, rank, week)`
  - `rank`：热门名次（列表按此排序）
  - `week`：星期几（周一=0 … 周日=6）
- 每次更新采用"拆表重建"策略，保证表结构与数据始终一致
- 界面线程与抓取线程分离，抓取在后台进行，界面不卡顿

**免责声明**：本项目仅用于个人学习与兴趣，数据来源于 Steam 公开页面，与 Steam / Valve 无任何关联；请勿用于商业用途或高频抓取。
